# SAMP CLRP

Client SA-MP Android gratis dari **Benyek Store** untuk City Lights Roleplay (dulu bernama Benyek SAMP).

Website: https://comun.benyekroblox.my.id/samp-clrp

## Download

Ambil APK terbaru di folder **[dist](dist)** (file `SAMP-CLRP-<versi>.apk`) atau di website https://comun.benyekroblox.my.id/samp-clrp.
Versi lama ada di halaman **[Releases](../../releases)**.

## Kenapa aman

- Izin Android hanya yang dipakai: **internet**, **mikrofon** (voice chat in-game, bisa ditolak) dan **pasang aplikasi** (khusus untuk memasang update SAMP CLRP sendiri). Tidak ada akses kontak, SMS, lokasi, atau overlay.
- Update otomatis: setiap dibuka, aplikasi mengecek versi terbaru di website Benyek Store. APK update diunduh dari repo ini (folder `dist`) dan dicek SHA-256-nya sebelum dipasang.
- Tanpa iklan dan tanpa pelacakan.
- **Tidak membawa file game.** Pakai file GTA San Andreas milikmu sendiri (lihat di bawah).
- Setiap rilis disertai `SHA256.txt`. Cocokkan hash file yang kamu unduh supaya yakin itu APK asli, bukan versi palsu dari pihak lain.

Unduh hanya dari halaman ini atau website Benyek Store. APK SAMP CLRP dari sumber lain bukan rilis resmi.

## Memasang file GTA San Andreas

SAMP CLRP hanya client, file game kamu pasang sendiri secara manual. Tidak perlu aplikasi GTA SA terpasang.

1. Siapkan file GTA SA milikmu: `base.apk`, `split_config.arm64_v8a.apk`, dan file `.obb` (atau ZIP berisi `anim/ audio/ data/ models/ texdb/ text/`).
2. Buka tab **Mod** di SAMP CLRP, lalu salah satu:
   - **Pilih file game** → pilih semua file sekaligus, atau
   - salin file ke `Android/data/id.benyekstore.sampclient/files/impor/` lewat file manager/PC, lalu tekan **Pindai folder impor**.
3. Tunggu sampai muncul *File game lengkap*.

APK launcher SA-MP lain juga bisa dipakai: SAMP CLRP hanya mengambil engine GTA SA-nya, library launcher itu (misalnya `libsamp.so`) tidak ikut dipasang.
